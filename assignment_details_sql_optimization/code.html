SQL Optimization Assignment

schedule 45 min estimated
event Due Oct 12, 2024
adjust Not Started

01 Assignment Overview

In this assignment, you will be tasked with identifying and resolving performance bottlenecks within a provided e-commerce database schema. The dataset contains several million rows simulating order history, user sessions, and inventory logs.

Your objective is to analyze a set of slow-running queries, interpret their execution plans, and apply appropriate indexing strategies and query rewrites to reduce execution time by at least 80% while minimizing the storage overhead of new indexes.

02 Requirements

  • check_circle Optimized SQL script containing your revised queries and index creation statements.
  • check_circle Performance report PDF detailing the 'before' and 'after' execution times and explain plans for each query.

03 Instructions

1

Download and initialize the dataset

Import the provided `.sql` dump into your local PostgreSQL instance. Note that the import process may take a few minutes due to the data volume.

2

Identify bottlenecks

Run the baseline queries provided in the starter script. Use `EXPLAIN ANALYZE` to capture the initial execution metrics.

3

Optimize and submit

Apply your optimizations. Once the target performance is reached, compile your final scripts and report, and submit them using the form on this page.
