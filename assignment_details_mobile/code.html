SQL Optimization Assignment

hourglass_empty Not Started

Overview

In this assignment, you will analyze a poorly performing database query and optimize it using indexes, query refactoring, and execution plan analysis. The goal is to reduce query execution time by at least 80% on a dataset of 1 million rows.

Requirements

  • check_circle Submit the original and optimized SQL queries.
  • check_circle Provide EXPLAIN plan outputs for both queries.
  • check_circle Include a brief written analysis (max 300 words) explaining your optimization strategy.

Instructions

1
Download Dataset Download and import the provided e-commerce dataset into your local PostgreSQL environment.
2
Analyze Baseline Run the unoptimized query provided in `baseline.sql` and record its execution time and plan.
3
Optimize & Document Refactor the query, add necessary indexes, and write your analysis comparing the performance.
